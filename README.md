# Studious Lamp

Authoritative public product and runtime for the coordinated Studious system.

Studious Lamp owns public contracts, Core authorization and lifecycle behavior, repositoryd,
duckdbd/Quack integration, public HTTP/MCP interfaces, and product-facing integrations. Private
source acquisition, extraction profiles, and Candidate production remain outside this repository.

## Status

Pre-1.0 greenfield development. Public contract and runtime implementation will be introduced
through owner-local Spec Kit tasks.
